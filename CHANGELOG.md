# Changelog

Each release has a section headed `## vX.Y.Z`. The Updates page in the app
shows these notes to the user, so write them for the person entering data.

## v0.2.0 — 2026-10-04
- New **Updates** page (top right of the menu). SAR Log checks for a newer
  version when it starts; one click downloads it, and "Restart now" finishes
  the update. Your records are never touched, and a backup is made first.
- If an update causes trouble, "Go back" returns to the previous version.
- The version number is shown in the menu.

## v0.1.0 — 2026-10-03
- First version: jobs with your own fields, person hours by organisation,
  people, training records and summaries, reports, CSV exports and change
  history.
